`StyleValidator` and `OptionsValidator` are the entry points. Each runs the
depth check, the schema validation and the checks the schema cannot express.

`StyleSchemaValidator.js` and `OptionsSchemaValidator.js` are auto-generated by
`scripts/compile-schema.mjs` from `@dicebear/schema` using
[@exodus/schemasafe](https://github.com/ExodusMovement/schemasafe)'s
`toModule()` output. The corresponding `.d.ts` files are maintained manually.

To regenerate, run `npm run prebuild` from the package root.
