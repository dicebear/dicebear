DiceBear is free and MIT licensed. There is no paid tier and no company behind
it. If you use it and want to give something back, you have a few options.

<template #star>

It makes the project easier to find for the next person looking for an avatar
library.

</template>

<template #code>

Bug reports and pull requests are welcome in all repositories. The guide
explains where each kind of change belongs and how to set the projects up
locally.

</template>

<template #styles>

New avatar styles are the contribution users notice most. There are guides for
creating a style with Figma and from scratch.

</template>

<template #answer>

Integration questions come in through GitHub Discussions. Most of them can be
answered by anyone who has used DiceBear in a real project.

</template>

<template #sponsor>

bunny.net supports DiceBear with CDN infrastructure. It sits in front of the
hosted API, so the API stays free of charge.

</template>
